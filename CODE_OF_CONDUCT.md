# Community conduct

Treat contributors and reviewers with respect. Discuss claims and sources rather than people. Do not post harassment, discrimination, private contact details, or unlicensed material. Maintainers may edit, hide, or close contributions that violate these expectations, and should give a brief reason when practical.

For now, raise conduct concerns privately with the repository owner through their GitHub profile rather than in a public issue. A dedicated private contact channel can be added when the public repository is configured.
