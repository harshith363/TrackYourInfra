# Project governance

TrackYourInfra begins with one repository owner as maintainer. Maintainers decide which proposals become accepted data, explain declined decisions, and preserve the public change trail. Geography-specific reviewers can be added after they agree to serve; do not assign unconfirmed people or GitHub handles.

The main branch should require pull requests and passing validation checks. An independent approval should be required once a second maintainer is available. A one-person repository needs a documented path for owner-authored changes that does not deadlock branch protection. The exact repository settings are applied when the public remote exists.

Contributors retain credit through GitHub history unless they request no additional site credit. Reports are public. Do not collect private contact details through issue forms. Code is MIT licensed; third-party map assets keep the licenses documented in the map data notes.
