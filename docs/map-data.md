# India boundary

`public/maps/india-boundary.geojson` is derived from DataMeet's `india-composite.geojson`, retrieved on 28 September 2026.

- Source and licensing: https://github.com/datameet/maps/tree/master/Country
- Original file: https://raw.githubusercontent.com/datameet/maps/master/Country/india-composite.geojson
- License: CC0, as specified for the composite file (other files in that collection have different licenses).
- Depiction: includes disputed territories in accordance with India's official territorial depiction, including the full Jammu & Kashmir and Ladakh region. This is a display boundary, not a statement about actual administration or a surveyed/legal boundary product.
- Processing: Ramer–Douglas–Peucker simplification with a 0.006-degree tolerance; coordinates rounded to five decimal places. All 80 polygon parts retained, including islands. Rings that would collapse were retained from the original.
- Size: 7,761 coordinate positions, approximately 150 KB; no runtime boundary requests to third-party services.
- Extent: longitude 68.16438–97.39536; latitude 6.75292–37.09759.
